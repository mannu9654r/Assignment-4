# 🧺 Fresh Fold - Laundry Service Web App

This is a simple laundry service web application where users can view services, add items to cart, and book laundry pickup. The booking form sends email using EmailJS.

---

## 🚀 Live Demo
https://aquamarine-pegasus-d0ec75.netlify.app/

---

## 📌 Features

- Responsive navbar
- Hero section with scroll button
- Services listing (Wash, Dry Clean, Ironing)
- Add to cart system with quantity support
- Live cart total calculation
- Booking form with EmailJS integration
- Newsletter subscription form with validation

---

## ⚙️ Technologies Used

- HTML
- CSS
- JavaScript (Vanilla JS)
- EmailJS (for sending emails)

## ▶️ How to Run the Project

1. Download or clone the repository
2. Open `index.html` in any browser
3. Make sure internet is connected (for EmailJS + fonts)
4. Add items and test booking form

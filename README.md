# Fresh Fold Laundry Website

This is a simple laundry service website made using HTML, CSS and JavaScript.

Features:
- Responsive Navbar
- Laundry Services Section
- Add to Cart
- Quantity Update
- Booking Form
- EmailJS Integration
- Newsletter Subscribe
- Responsive Design

## How to Run

1. Download the project
2. Open folder in VS Code
3. Open index.html in browser

## EmailJS Setup

1. Create account on EmailJS
2. Create service and template
3. Add Public Key
4. Replace keys inside script.js
